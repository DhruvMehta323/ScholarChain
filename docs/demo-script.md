# ScholarChain demonstration script

Draft (Phase 17a). Target length: 9 minutes 50 seconds. The course specification names no length for the video; the work order sets 10 minutes or less. The outline covers all 22 items of the course specification section "Demonstration requirements", in the work-order flow: agent factory, one phase run, AWS deployment, real query with evidence, elasticity, cleanup. The demonstration must not rely only on prerecorded screenshots (same section), so each shot below is a live terminal or console action; shots that need the deployed AWS stack are marked `[[PENDING-AWS]]` and cannot be recorded until Phases 14 and 15c are accepted.

Narration rule: say only what the repository evidence supports; read numbers from the file on screen, never from memory.

## Before recording (human, outside the timed video)

1. Fresh clone at the submitted tag (`[[HUMAN: tag]]`) with the toolchain from [README.md](../README.md) section 5. A clean `sbt check` takes between roughly 15 minutes and 38 minutes on the author's machine ([phase-08 gate](agent-runs/phase-08-embeddings-vectors/human-gate.md) section 4: "A full CHECK now takes 15-38 minutes"; the Phase 15b run took 1,515 s), so run it before recording and show the real console tail and `.claude/.last-test-run` in the video.
2. Local data present under the gitignored `datasets/raw/` (see [datasets/scripts/FETCH-SCALE.md](../datasets/scripts/FETCH-SCALE.md)) and a finished local pipeline run to show (the Hadoop and Spark commands are in the module contracts).
3. AWS: deployed stack in an environment window (`bash scripts/env-window.sh up` printed steps, human apply), key file outside the repository, ingress limited to your /32 `[[PENDING-AWS]]`.
4. Open terminals at the repository root; nothing secret on screen (no key, no account ID, no ORCID iD). Redact the account ID in any console screenshot or terminal prompt.
