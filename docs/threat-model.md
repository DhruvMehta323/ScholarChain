# ScholarChain threat model

Draft (Phase 17a). Each row names the threat, the control that the committed repository contains, where the control is specified or tested, and its evidence class. Evidence classes: **L** local test or hook behavior, **F** fixture demonstration, **A** AWS-validated (none exists yet: `[[PENDING-AWS: every control that depends on deployed IAM, network or service behavior is unverified until Phase 14]]`). A control that is documented but not exercised is labeled "specified". Nothing here claims a penetration test.

Scope: the build-time agent factory (section 1), the data pipeline (section 2) and the deployed runtime (section 3). The seven classes requested by the work order (prompt injection, data poisoning, credential exposure, over-permission, denial of service, destructive commands, provenance tampering) and every bullet of the course specification section "Security requirements" are covered; a final table lists the specification bullets with no control.
